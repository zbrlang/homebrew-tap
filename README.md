# ZBR Homebrew Tap

Official repository for ZBR CLI distribution via Homebrew.

## Installation
```bash
brew tap zbrlang/tap
brew install zbr
```

## Notes
This repository is managed automatically via GitHub Actions in the main [zbr repository](https://github.com/zbrlang/zbr).

## More Information
Visit the [official ZBR website](https://zbrlang.tech) for more information.
